# Angular 19 E-Commerce Application

## Overview

A simple E-Commerce application built with Angular 19 using Standalone Components, Signals, Reactive Forms, Lazy Loading, and localStorage.

## Features

* Product Listing with Search & Category Filter
* Add to Cart functionality
* Cart Management (Increase/Decrease Quantity, Remove Item, Grand Total)
* Contact Us Reactive Form with Validations
* Loading and Empty States
* localStorage Persistence

## Technologies

* Angular 19
* Tailwind CSS
* TypeScript
* Signals
* Reactive Forms
* Lazy Loaded Routes
* localStorage

## Setup
npm install
ng serve
```

Open: http://localhost:4200

## State Management

Cart state is managed using Angular Signals and persisted in localStorage.
